## Technical Focus & Research

I design and build next-generation machine learning architectures and high-throughput systems infrastructure. My research bridges continuous Lie-group symmetries in recurrent neural models, million-token context compression, and distributed streaming data architectures:

* **Neural State Space Models (SSMs)**: Author of **QU-SSM**, deriving $\mathrm{SO}(2)$ isometric state updates with bounded soft-decay highways to achieve true $\mathcal{O}(1)$ inference memory without quality degradation.
* **Code Intelligence Engines**: Author of **Ael-Coder-1.5B**, implementing continuous Lie-manifold Cayley transport for million-token codebase ingestion on consumer hardware.
* **Distributed Lakehouse & Cloud Systems**: Designing real-time streaming architectures with Apache Spark, Apache Kafka, Next.js, and FastAPI.
